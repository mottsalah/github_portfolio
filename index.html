Projects

Severn Trent Water Demand Forecasting & Scenario Analysis

Python | pandas | Excel | Power BI | DAX | Scenario Analysis

Built an independent public-data prototype using Severn Trent's published WRMP24 Strategic Grid planning information to explore long-term water demand and supply-demand balance.

Developed a reproducible Python workflow to inspect, extract, reconcile and validate the published baseline across 25 financial years. Created a published baseline plus five illustrative demand sensitivities covering household consumption, population growth, non-household demand and leakage, supported by an Excel assurance workbook and interactive Power BI scenario explorer.

The combined efficiency sensitivity reduced projected 2044-45 demand by 161.1 Ml/d, or 12.7%, compared with the published baseline and improved the modelled supply-demand balance from approximately -235.1 Ml/d to -73.9 Ml/d.

NHS Emergency Department Operational Performance Dashboard

Power BI | Power Query | SQL | Python | Excel

Built an end-to-end analytical workflow using NHS England Monthly A&E Attendances and Emergency Admissions data covering April 2021 to March 2026.

Consolidated and validated 60 monthly source files containing 12,127 provider-month records, created a relational SQLite analytical model and reusable SQL analysis, and developed Power BI reporting for national trends, provider performance, benchmarking and data quality.

Developed measures covering four-hour performance, target variance, year-on-year change, three-month rolling performance, provider rankings, emergency admissions and long decision-to-admit waits, supported by automated validation throughout the data pipeline.

Local Authority Population & Infrastructure Scenario Model

Python | pandas | SQL | Excel | Power BI

Developed a scenario-planning model using ONS Subnational Population Projections to investigate how demographic change could affect future pressure on public-service infrastructure across English local authorities.

Cleaned and validated more than 1.3 million projection records covering 309 local authorities, 2022 to 2047 and three migration scenarios. Loaded the processed data into SQLite and created reusable SQL analyses for growth rankings, scenario uncertainty and demographic pressure.

Built interactive Power BI views covering population growth, scenario comparison and projected demand indices for areas including education, older populations and high-intensity care.
